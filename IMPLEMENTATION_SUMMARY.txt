CRITICAL DESIGN DECISIONS
═════════════════════════════════════════════════════════════════════════════════

✅ PLUG-IN ARCHITECTURE
   → New strategies inherit Strategy, override scan()/manage()
   → Backtester unchanged when adding strategies
   → Easily testable, maintainable

✅ SINGLE CODEBASE FOR BACKTEST & LIVE
   → Same strategy.scan() and strategy.manage() everywhere
   → No duplicate logic
   → Live behavior = backtest behavior (trust it)

✅ REALISTIC COSTS
   → Every Zerodha charge modeled and deducted
   → No "optimistic" results
   → P&L already net of all costs

✅ NO LOOK-AHEAD
   → Signal on close T
   → Order placed T+1
   → Fill T+1 only (can't use T+1 open/close to decide entry)
   → Backtest matches real-world timing

✅ CONFIGURATION-DRIVEN
   → All parameters in config.yaml
   → Secrets in environment variables
   → No hardcoded values anywhere
   → Easy to swap strategies, parameters, configs

✅ GEMINI AI (REPORTS ONLY)
   → Used for daily summaries and event screening
   → NEVER for signal generation or position sizing
   → Humans decide trade/no-trade, AI reports results

✅ PORTFOLIO GUARDS
   → Sector concentration limits (max 2)
   → Position count limits (max 5)
   → Open risk caps (max 5%)
   → Monthly drawdown halt (-6%)
   → Order rejection monitoring
