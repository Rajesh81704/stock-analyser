COMMON ISSUES & SOLUTIONS
================================================================================

Issue: Win rate is 35% instead of 49%
Solution: Check if you're trading illiquid stocks. Return to NIFTY 100 only.
          Verify stop-loss is set correctly (0.45 ATR).

Issue: Getting too many stop-outs in first 5 minutes
Solution: Opening range is 09:15-09:45. Don't trade until 09:45+.
          Wait for range to complete before entries.

Issue: Slippage is 3x worse than backtest
Solution: Consider trading only top 20 mega-caps (RELIANCE, TCS, INFY, etc).
          Increase minimum turnover filter to ₹50Cr.

Issue: System crashed during trading hours
Solution: Manually close all positions immediately.
          Review logs in results/trading.log.
          Set up alert system or manual intervention plan.

Issue: Losing more than 2% daily
Solution: Activate daily loss stop. Exit all positions.
          Review that day's trades for execution errors.
          Resume only next trading day.
