HOW IT WORKS
════════════════════════════════════════════════════════════════════════════════

HOURLY CYCLE (Repeats 7 times/day):

1. FETCH DATA
   ├─ Loads daily OHLCV for 501 NIFTY stocks
   ├─ Uses local cache (CSV/Parquet) for speed
   └─ Falls back to yfinance if needed

2. SCAN FOR SIGNALS
   ├─ Run EMA Pullback scanner
   │  ├─ Check pullback to 20 EMA
   │  ├─ Verify ADX > 20 (trending)
   │  ├─ Look for bullish rejection (hammer/engulfing)
   │  └─ Calculate risk/reward
   │
   └─ Run 52WH Breakout scanner
      ├─ Check price near 52-week high
      ├─ Verify volume & momentum
      ├─ Validate breakout structure
      └─ Calculate risk/reward

3. AUTO-ENTER TRADES
   ├─ Check portfolio limits (max 5 open)
   ├─ Verify risk calculation (1% per trade)
   ├─ Create position with stop loss & target
   ├─ Log entry to execution_log.json
   └─ Update equity in state.json

4. SAVE RESULTS
   ├─ Append to nifty500_scan.log
   ├─ Update hourly_scan_results.json
   ├─ Update state.json (equity tracking)
   └─ Update execution_log.json (all trades)
